# Simple Interest Calculator

This project calculates simple interest using the formula:

SI = (P × R × T) / 100

## Inputs:
- P → Principal amount
- R → Rate of interest
- T → Time (years)

## Output:
- Simple Interest

## Example:
If P = 1000, R = 5%, T = 2 years  
SI = (1000 × 5 × 2) / 100 = 100
